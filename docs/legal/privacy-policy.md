# 隐私政策

**更新日期：2026年5月15日**

**生效日期：2026年5月15日**

章鱼公益平台（以下简称“平台”或“我们”）重视您的个人信息与隐私保护。本政策说明您使用平台网站、控制台和 API 服务时，我们如何收集、使用、存储、共享和保护相关信息，以及您可以如何行使自己的权利。

您应在使用服务前完整阅读本政策。注册、登录、充值、创建或使用 API Key、调用接口，或以其他方式继续使用平台服务，表示您已了解本政策所述的数据处理活动。对于依法需要单独同意的处理，我们会另行征求您的同意。

::: danger 服务地区限制
平台不向中国大陆地区用户提供服务。位于中国大陆地区的个人或组织，请勿注册、登录、充值或调用接口，也不要向平台提交个人信息。

本政策所称“中国大陆地区”不包括香港特别行政区、澳门特别行政区和台湾地区。
:::

## 1. 本政策的适用范围

本政策适用于平台网站、控制台、API、客服和与服务直接相关的数据处理。第三方网站、客户端、SDK、支付页面或上游模型服务可能有各自的隐私规则，您还应阅读相应第三方政策。

## 2. 我们收集的信息

我们遵循必要、合理和与目的相关的原则，可能根据您实际使用的功能收集以下信息。

### 2.1 账号与身份信息

- 用户名、昵称、邮箱、手机号及您主动填写的其他注册信息。
- 加密存储的密码摘要、登录状态、验证记录和账号安全设置。
- 如未来依法开展个人或企业认证，我们将在收集前说明所需字段、目的和处理方式。

### 2.2 交易与财务信息

- 订单号、充值金额、币种、时间、支付渠道、订单状态、退款或争议处理记录。
- 支付服务商返回的必要交易标识和结果信息。平台通常不会直接获取或保存完整银行卡号等支付敏感信息，具体以支付渠道实际流程为准。

### 2.3 API 调用与使用日志

- 请求时间、接口路径、模型标识、API Key 标识、请求量、响应状态、错误信息、延迟、Token 或其他计量结果及费用。
- 异常调用、限流、风控命中、密钥禁用、登录和重要操作记录。
- 为定位故障、处理投诉或防范滥用，日志可能在必要范围内包含请求或响应的技术摘要。请勿在请求中提交不必要的敏感信息。

### 2.4 请求内容、模型输出与附件

为完成模型调用，我们需要处理您提交的提示词、上下文、图片、音频、视频、文件引用、工具定义及模型返回内容，并将必要数据转发给相应上游服务。

平台可能因请求转发、缓存、安全检查、故障排查或合规要求，对相关内容进行临时处理或在必要期限内保存。具体处理范围会受功能、上游服务和系统配置影响。您应按照“提交内容可能被平台及上游处理”的原则评估数据风险。

### 2.5 设备、网络与 Cookie 信息

- IP 地址、访问时间、来源页面、浏览器类型、操作系统、语言、设备和网络信息。
- Cookie、本地存储或同类技术生成的会话、安全和偏好标识。

### 2.6 您主动提供的信息

您通过客服、工单、邮件或其他沟通渠道提交的文字、截图、文件、联系方式及问题描述。

## 3. 我们如何使用信息

我们可能将上述信息用于：

1. 创建和管理账号，完成登录验证、API 鉴权及权限控制。
2. 提供模型调用、API 密钥创建与维护、用量统计、余额扣费和账单查询。
3. 生成和核对订单，处理充值、退款、争议和异常交易。
4. 进行反欺诈、反滥用、异常检测、限流、安全审计和事件处置。
5. 处理咨询、工单、投诉、故障定位和服务通知。
6. 维护、分析和改进服务性能、兼容性及用户体验，必要时采用汇总或去标识化数据。
7. 履行法律法规、司法机关、行政机关或其他有权机构依法提出的要求。
8. 验证服务地区和使用资格，防止通过虚假信息或技术手段绕过地区限制。

我们不会以出售个人信息作为日常经营方式，也不会将您的个人信息用于与上述目的无关的处理，除非另行告知并取得适用法律要求的授权。

## 4. Cookie 与同类技术

平台可能使用 Cookie 或同类技术维持登录状态、保存界面偏好、分析基本访问情况并防范恶意请求。

您可以通过浏览器管理或清除 Cookie。禁用必要 Cookie 后，登录、会话保持、安全验证等功能可能无法正常使用。第三方支付或外部服务设置的 Cookie 由相应第三方负责说明。

## 5. 信息共享、委托处理与披露

我们仅在实现服务所必需或法律允许的情况下共享信息。

### 5.1 上游模型与技术服务商

为完成 API 调用，您的请求内容、附件、模型参数和必要技术字段可能被转发给上游模型服务商。我们也可能使用云计算、网络、存储、日志、监控、邮件和客服等服务商处理必要信息。

我们会在合理范围内选择服务商，并通过合同、权限控制或其他措施要求其履行保密与安全义务，但其独立提供的服务仍可能适用其自身条款和政策。

### 5.2 支付服务商

为完成充值、退款和对账，我们会向支付渠道提供必要订单信息，并接收交易结果。您的支付信息由相应支付服务商按照其规则处理。

### 5.3 法律与安全要求

在法律法规要求、有权机关依法提出要求，或为保护用户、平台、第三方的人身财产和系统安全所必需时，我们可能依法保存或提供相关信息。

### 5.4 业务变更

如发生合并、收购、重组、资产转让、破产清算或类似交易，相关信息可能作为交易的一部分转移。我们将要求承接方继续受本政策约束，或依法重新征得您的授权。

### 5.5 公开披露

除获得您的明确授权或法律法规另有规定外，我们不会公开披露您的个人信息。

## 6. 跨境传输与处理

平台及上游服务的服务器、运营人员或技术服务商可能位于您所在国家或地区之外。使用 API 时，相关数据可能被跨境传输和处理，不同司法辖区的数据保护标准可能存在差异。

我们会根据适用法律采取合理的合同、权限和安全措施。您应确认自己有权将提交的数据传输给平台和相关上游，并满足所在地对跨境传输、数据本地化或特定行业数据的要求。

## 7. 数据存储、保存期限与清理

1. 账号信息通常在账号存续期间保存，并在注销后按法律要求、争议处理和安全需要保留必要记录。
2. 交易、账单和财务记录按照适用法律、支付规则和审计需要保存。
3. 调用与安全日志仅在计费核对、故障排查、反滥用和合规所需期限内保留，并按平台实际策略定期清理。
4. 请求内容和附件的保存方式取决于具体功能、系统设置和上游服务；无需长期保存时，我们会在合理期限内删除或去标识化。
5. 超过保存期限或处理目的已经实现后，我们将删除或匿名化相关信息，法律要求继续保存的除外。
6. 备份中的删除可能存在合理延迟；在覆盖前，我们将限制其用于恢复和安全目的。

## 8. 信息安全保护

我们根据业务风险采取合理可行的安全措施，包括：

- 使用 HTTPS 等方式保护传输过程。
- 对密码摘要、API Key 等重要凭证采取适当的存储与展示保护。
- 实施访问控制、最小权限、日志审计和异常告警。
- 采取备份、恢复、漏洞修复和安全事件处置措施。
- 限制内部人员和服务商访问数据的范围。

互联网和模型服务链路无法做到绝对安全。发生个人信息安全事件时，我们将及时采取补救措施，并按照适用法律履行通知或报告义务。

## 9. 您的权利

在适用法律允许的范围内，您可能享有以下权利：

1. 访问和更正账号中的个人信息。
2. 请求删除不再必要、违法处理或依法应删除的信息。
3. 申请注销账号；依法需保留的交易、安全和争议记录除外。
4. 对基于同意的处理撤回同意。撤回不影响此前处理的合法性，但可能导致相关功能无法继续使用。
5. 根据所在地法律，请求限制或反对特定处理、获取数据副本或行使数据可携带权。
6. 对自动化风控或账号处置结果提出说明和复核请求，但平台可为防止安全规则被绕过而限制披露具体算法细节。

为保护账号和数据安全，我们可能要求您验证身份。明显重复、超出合理范围、影响他人权益或法律允许拒绝的请求，可能无法处理或需要收取合理成本。

## 10. API 使用者的责任

如果您通过平台处理最终用户的数据，您通常是相关数据的收集方或决定处理目的的一方。您应：

- 向最终用户提供充分的隐私告知并取得必要授权。
- 只提交实现明确目的所需的数据，并设置合理保存期限。
- 不向平台提交无权处理的个人信息、机密或受限制数据。
- 对传输前后的数据实施访问控制、加密、脱敏和删除措施。
- 响应最终用户依法提出的权利请求，并履行所在地的合规义务。

## 11. 未成年人保护

平台不面向未达到所在地法定成年年龄的人提供服务。未成年人请勿注册、充值、创建 API Key 或提交个人信息。若我们发现不当收集了未成年人信息，将根据适用法律采取删除、限制账号或其他必要措施。

## 12. 第三方链接与客户端

文档或控制台可能包含第三方网站、SDK、应用或插件链接。第三方独立收集和处理的信息不受本政策控制。请在使用前阅读其隐私政策，并谨慎配置 API Key 和数据权限。

## 13. 本政策的更新

我们可能根据法律法规、服务功能、上游处理方式或安全需要更新本政策，并公布更新日期和生效日期。重大变更生效前，我们将通过站内公告、页面提示或其他合理方式提供更显著的通知。

如您不同意更新后的政策，应停止使用相关服务并处理账号；在生效日期后继续使用，表示您已了解更新后的处理规则。
