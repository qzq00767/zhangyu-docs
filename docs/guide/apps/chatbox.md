# Chatbox

简洁易用的 AI 桌面/移动端客户端，全平台支持。

## 安装

从 [Chatbox 官网](https://chatboxai.app/) 下载，支持 Windows、macOS、Linux、iOS、Android。

## 配置

### 桌面端

1. 打开 Chatbox → **设置** → **模型**
2. 选择 **OpenAI API**
3. 填入配置：

| 设置项 | 值 |
|--------|-----|
| **API 地址** | `https://{{BASE_URL}}/v1` |
| **API 密钥** | 你的章鱼中枢 API Key |
| **模型** | 选择需要的模型（如 `gpt-4o`） |

### 移动端

移动端配置相同，在设置页面填入 Base URL 和 API Key。

## 生图设置

Chatbox 支持对话式生图：
1. 设置 → 模型 → 选择 `gpt-image-2` 等绘图模型
2. 在对话中直接描述图片

## 推荐模型

| 场景 | 推荐模型 |
|------|---------|
| 日常聊天 | `gpt-4o` |
| 翻译 | `gpt-4o-mini`（高性价比） |
| 编程问答 | `claude-sonnet-4-6` |
| 生图 | `gpt-image-2` |

## Chatbox 优势

- ✅ 数据本地存储，隐私安全
- ✅ 全平台覆盖，数据同步
- ✅ 界面简洁，开箱即用
- ✅ 支持多会话管理
