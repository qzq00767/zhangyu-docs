# 图片尺寸参考

不同模型支持的分辨率一览。

## Imagine2 / GPT Image 2

### 1K 分辨率（gpt-image-2-1k）

快速生成，适合头像、封面草稿、预览图。

| 尺寸 | 宽高比 |
|------|:----:|
| `1024x1024` | 1:1 |
| `1536x1024` | 3:2 |
| `1024x1536` | 2:3 |
| `1824x1024` | 16:9 |
| `1024x1824` | 9:16 |

### 2K 分辨率（gpt-image-2-2k）

中等分辨率，适合海报、角色设定。

| 尺寸 | 宽高比 |
|------|:----:|
| `2048x2048` | 1:1 |
| `2048x1152` | 16:9 |
| `1152x2048` | 9:16 |
| `2048x1536` | 4:3 |
| `1536x2048` | 3:4 |

### 4K 分辨率（gpt-image-2-4k）

高分辨率成片素材，耗时长。

| 尺寸 | 宽高比 |
|------|:----:|
| `2880x2880` | 1:1 |
| `3840x2160` | 16:9 |
| `2160x3840` | 9:16 |
| `3312x2480` | 4:3 |
| `2480x3312` | 3:4 |
| `3840x1648` | 21:9 |

## DALL-E 3

| 尺寸 | 说明 |
|------|------|
| `1024x1024` | 正方形（默认） |
| `1792x1024` | 宽屏 |
| `1024x1792` | 竖屏 |

## Grok 图片

| 尺寸 | 宽高比 |
|------|:----:|
| `1024x1024` | 1:1（推荐图生图固定使用） |
| `1792x1024` | 16:9 |
| `1024x1792` | 9:16 |
| `1280x720` | 16:9 |
| `720x1280` | 9:16 |

## Grok 视频

| 尺寸 | 宽高比 |
|------|:----:|
| `1024x1024` | 1:1 |
| `1792x1024` | 16:9 |
| `1024x1792` | 9:16 |

::: tip 建议
- 模型名和尺寸档位保持一致：1K 模型配 1K 尺寸，4K 模型配 4K 尺寸
- 4K 图耗时更长，调用方超时建议设置更大（600s+）
- 生成视频建议 `resolution_name=720p`，`preset=normal`
:::
